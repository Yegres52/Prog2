# Последний свет

Небольшая визуальная новелла на Vue 3. Работает в браузере на компьютере и телефоне.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5175/. Для телефона откройте сетевой адрес, который напечатает Vite, находясь в той же сети.

## Как выполнено задание

- Сюжет и варианты действий хранятся в `public/story.json`.
- Три переменные: доверие, смелость и улики. Некоторые варианты доступны только при нужном значении.
- Прогресс сохраняется в `localStorage` браузера.
- Файл сюжета запрашивается заново при запуске, возвращении на вкладку и раз в минуту. При обновлении существующая сцена и переменные сохраняются; если сцена удалена, игра начинается заново.
- Серверный код не используется. Команда `npm run build` создаёт статические файлы в `dist/`, которые можно загрузить на статический хостинг.

Чтобы изменить сюжет, отредактируйте `public/story.json` и увеличьте поле `version`.

## Публикация на GitHub Pages

1. В репозитории `Yegres52/Prog2` откройте **Settings → Pages** и выберите **GitHub Actions** в разделе **Build and deployment → Source**.
2. Отправьте изменения в ветку `main`. Workflow `.github/workflows/pages.yml` установит зависимости, соберёт проект и опубликует `dist/`.
3. После успешного выполнения workflow сайт будет доступен по адресу `https://yegres52.github.io/Prog2/`.

Локально используйте `npm run dev` и `http://localhost:5175/`. Для Pages Vite добавляет префикс `/Prog2/` к ресурсам. Обновления `public/story.json` публикуются вместе со следующим коммитом; открытая игра проверяет новую версию при возврате на вкладку и каждую минуту.

## Структура

- `src/App.vue` — главная страница.
- `src/components/NovelScene.vue` — отображение сцены и кнопок выбора.
- `src/composables/useNovel.js` — состояние игры и проверка обновлений.
- `src/game.js` — правила переходов и работа с показателями.
- `src/storyStore.js` — загрузка JSON и сохранение прогресса.
